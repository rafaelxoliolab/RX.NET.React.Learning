## What is React?

- React is a Javascript Library created by Facebook.
- React is used to build user interfaces, which are parts of a website or web app that user interact with.

## Key features
- React is Component-Based Arquitecture
    - Break complex UI's into small reusable componentes
- Fastest updates with Virtual DOM
    - Efficient updates, by only changing what is necesary.
- Declarative Approach
- Vast library of third party componentes and tools.
- Companies that use React: Facebook, Netflix, AirBnB and Uber among others.
